# Xnova — сайт компьютерного клуба

Многостраничный сайт компьютерного клуба Xnova (Минск, ул. Сергея Есенина, 6): тарифы по залам, галерея, контакты. Яркий оранжево-чёрный дизайн в стиле постера, FAQ в виде чата, адаптив, анимации. Чистые HTML, CSS и JS без сборки.

**Страницы:** `index.html`, `prices.html` (тарифы с переключателем будни/выходные), `visit.html` (первый визит), `contacts.html`.

## Что менять
Всё в `js/data.js`: `SITE` (адрес, телефон, соцсети), `HALLS` (залы и цены), `FAQ` (вопросы и ответы для чата).

## Публикация на GitHub Pages
Залей содержимое папки в корень репозитория (не `.zip`), затем **Settings → Pages → Deploy from a branch → `main` / `(root)`**.

Сайт сделал [Lexey](https://t3trix-hub.github.io/t3trix-portfolio/). Логотип, фото и названия принадлежат клубу.
